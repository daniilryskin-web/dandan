# Advanced-чарт DataLens: полоса-состав

Седьмой чарт набора: одна горизонтальная полоса из трёх мер, без измерения по
оси Y. Итог стоит в шапке справа.

## Раскладка по вкладкам

| Файл | Вкладка |
|---|---|
| `Meta.json` | Meta |
| `Params.js` | Params |
| `Sources.js` | Sources |
| `Prepare.js` | Prepare |
| `Controls.js` | Controls |

## Подключение датасета

Во вкладку **Meta** обязательно вписывается id датасета:

```json
{"links": {"compositionDataset": "<id из адреса .../datasets/ID>"}}
```

Измерения у этого чарта нет: `Sources.js` запрашивает только три меры, а
`SERIES_SPEC` в `Prepare.js` задаёт их порядок и цвета. Если источник вернёт
несколько строк, значения складываются — иначе чарт молча показывал бы только
первую.

## Итог в шапке

Полоса занимает всю ширину области построения, поэтому за её концом места для
подписи не остаётся — итог вынесен в правый верхний угол (`ВСЕГО 235`).
`TOTAL_LABEL` меняет слово перед числом, `SHOW_TOTAL = false` убирает итог
совсем.

Шкалы и сетки нет намеренно: полоса показывает состав целого, а не величину
на оси, и деления здесь были бы лишним шумом.

## Цифры

Значение стоит внутри своего сегмента. Узкий сегмент расширяется ровно до
ширины подписи, недостающие пиксели снимаются с крупных пропорционально их
запасу — общая длина полосы не меняется. `fitLabels: false` выключает
подгонку; тогда у маленьких долей цифры не будет.

Цвет подписи выбирается по контрасту с заливкой: белый на тёмных ступенях,
чернильный на светлой лаванде.

Скруглены только внешние концы полосы, между сегментами просвет 2 px.

## Если полоса пустая

Чарт называет причину под заголовком: «Источник не вернул ни одной строки»
или «Ни одна из мер не пришла со значением больше нуля» с перечислением
полей, которые реально пришли. Пустая полоса без объяснения читается как
поломка вёрстки.

## Проверка

```
node dev/check.js               # изоляция рендера + четыре размера холста
node dev/preview.js 960 220     # обновляет preview.html
```

## Что проверено

* Рендер в Chromium на 960×220: 65 / 16 / 154, итог 235 — совпадает с вашим
  визардом, все три цифры внутри своих сегментов.
* Мелкие доли: 1 / 2 / 400 — единица и двойка читаются внутри сегментов.
* Узкий холст 420×240: легенда переносится в два ряда, полоса не ломается.
* Пустой источник: показывается причина, а не пустая плитка.
* `dev/check.js` проходит на четырёх размерах холста.

Не проверено вживую (нет доступа к инстансу DataLens): поведение
`Editor.generateHtml` на SVG-разметке.
