# WB+Ozon Checker v27.1

Программа для сбора карточек Wildberries и Ozon, извлечения ссылок на документы,
сверки с реестрами (ФСА, SWIS, BelGISS, EAEU) и выдачи финального вердикта.

## Что нового в v27.1 (хотфикс)

- Ozon-поиск исправлен: кириллический запрос больше не double-encode'ится в composer-api
- Добавлен устойчивый fallback Ozon через Playwright: если API/виджеты поиска изменились,
  программа открывает страницу поиска в браузере, перехватывает JSON и ссылки `/product/`
- Рекурсивный JSON-fallback Ozon достаёт карточки даже после переименования search-виджетов
- ФСА по умолчанию проверяется только браузером; киргизский SWIS остаётся быстрым HTTP-путём

## Установка на Windows

1. Скачайте Python 3.10 или новее с https://python.org. **Обязательно поставьте
   галочку «Add Python to PATH»** при установке.
2. Распакуйте архив `WBChecker_v27_final.zip` в любую папку.
3. Двойной клик по `install_windows.bat`. Дождитесь сообщения «Installation finished».
4. Двойной клик по `run_windows.bat`. Откроется окно приложения.

Если двойной клик не запускает приложение — откройте `cmd` в папке с программой
и выполните:
```
python -m pip install -U -r requirements.txt
python -m playwright install chromium
python wb_checker.py
```

## Режимы работы

1. **WB · Поиск (полный)** — два этапа: сбор карточек + проверка реестров
2. **WB · Поиск (этап 1)** — только сбор ссылок (быстро)
3. **WB · Поиск (этап 2)** — проверка реестров по сохранённому CSV
4. **WB · По бренду** — поиск всех карточек указанного бренда
5. **Ozon · Поиск** — поиск + парсинг реестров для Ozon
6. **Unified · WB + Ozon** — параллельный прогон обоих маркетплейсов с единым
   Excel-отчётом

## Реестры

- **ФСА** (`pub.fsa.gov.ru`) — браузерный путь по видимой карточке реестра; HTTP-fast-path отключён по умолчанию
- **SWIS** (`swis.trade.kg`) — быстрый HTTP-парсинг готового HTML
- **BelGISS** и **EAEU** — собирается только ссылка на документ

## Если что-то не работает

1. Откройте приложение и нажмите кнопку «Диагностика» — она покажет, чего не хватает.
2. Если в логах появляется `ModuleNotFoundError` — снова запустите `install_windows.bat`.
3. Если карточки не парсятся, но программа запускается — проверьте, что
   `playwright install chromium` прошёл успешно.
