# Advanced-чарт DataLens: сгруппированные полосы

Третий чарт набора: категории (ЖС / ЛиР / ТМУ) по вертикали, внутри каждой —
по полосе на год. Не стек: полосы не складываются, поэтому ни режима долей,
ни суммы в итогах здесь нет — суммировать разные годы в одну цифру нечего.

## Раскладка по вкладкам

| Файл | Вкладка |
|---|---|
| `Meta.json` | Meta |
| `Params.js` | Params |
| `Sources.js` | Sources |
| `Prepare.js` | Prepare |
| `Controls.js` | Controls |

## Подключение датасета

Во вкладку **Meta** обязательно вписывается id датасета:

```json
{"links": {"groupedDataset": "<id из адреса .../datasets/ID>"}}
```

Именно этого не хватало, когда чарт падал с
`Source with id "" was not found in the meta links`: `Editor.getId()` не нашёл
ключ в links и вернул пустую строку. Теперь `Sources.js` проверяет id сам и
пишет, что именно заполнить.

Названия полей правятся в `SERIES_SPEC` / `CATEGORY_FIELD` (`Prepare.js`) и в
`fields` (`Sources.js`). Ключ источника `grouped` должен совпадать с
`SOURCE_KEY`.

Поле категории называется `Год`, хотя содержит ЖС / ЛиР / ТМУ, а годами
названы меры — так в вашем датасете; в коде это отмечено комментарием, чтобы
следующий читатель не спотыкался.

## Цифры

Значение стоит внутри полосы, прижатое к её концу. Если полоса короче
подписи, цифра выносится сразу за конец полосы чернильным текстом — здесь это
ничего не искажает, в отличие от стека: полосы независимы, растягивать нечего.

Нулевое значение полосой не нарисовать, поэтому цифра `0` ставится
приглушённой у самой оси — иначе год молча пропадал бы из группы, как это
было в вашем визарде.

## Палитра

| Год | Цвет |
|---|---|
| 2025 | `#8E7CF2` |
| 2026 | `#4B2DE8` |
| 2027 | `#C0397E` |

Набор отличается от стековых чартов не по прихоти. В стеке `#4B2DE8` и
`#4A38AD` никогда не соприкасаются — между ними светлая ступень, и проверки по
соседним парам этого достаточно. Здесь полосы группы идут вплотную, и та пара
различается всего на ΔE 9.3, то есть читается как один цвет. Третья ступень
заменена на маджентовый акцент: набор проходит проверку **по всем парам**,
худшая пара — ΔE 20.0 при нормальном зрении и 14.2 при протанопии.

## Настройки в модели

| Ключ | Что делает |
|---|---|
| `groupRatio` | какую долю слота занимает группа полос (0.78) |
| `maxBarThickness` | предел толщины одной полосы (34 px) |
| `barGap` | просвет между полосами внутри группы (4 px) |
| `titleX` | отступ заголовка от левого края холста |

## Проверка

```
node dev/check.js               # изоляция рендера + четыре размера холста
node dev/preview.js 960 460     # обновляет preview.html
```

`dev/check.js` пересобирает функцию рендера в чистом контексте, где доступен
только `Editor` — это ловит обращения к переменным вне `wrapFn`, которые в
DataLens падают с `ReferenceError`.

Данные для предпросмотра лежат в `dev/fixture.js` и в код чарта не входят:
`Prepare.js` всегда читает `Editor.getLoadedData()`.

## Что проверено

* Рендер прогнан в Chromium на 960×460: ошибок нет, все девять значений на
  месте, порядок категорий и групп совпадает с вашим визардом.
* Краевые случаи: значение `1` (подпись уходит за конец полосы), `0` (цифра у
  оси, полосы нет), `120` (полоса во всю шкалу, подпись внутри).
* `dev/check.js` проходит на четырёх размерах холста.
* Палитра проверена по всем парам, а не только по соседним.

Не проверено вживую (нет доступа к инстансу DataLens): поведение
`Editor.generateHtml` на SVG-разметке.
