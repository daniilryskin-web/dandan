# Advanced-чарт DataLens: стек по направлениям

Четвёртый чарт набора: горизонтальный стек «Рефакторинг / Онлайн / Проактив»
по направлениям, сумма в конце полосы.

Рендер тот же, что в `../mincifry_bar_chart` — отличаются константы и две
добавки под длинные подписи (см. ниже). Это отдельная сущность в DataLens,
поэтому набор вкладок свой; палитра продублирована, менять цвета придётся во
всех копиях.

## Раскладка по вкладкам

| Файл | Вкладка |
|---|---|
| `Meta.json` | Meta |
| `Params.js` | Params |
| `Sources.js` | Sources |
| `Prepare.js` | Prepare |
| `Controls.js` | Controls |

## Подключение датасета

Во вкладку **Meta** обязательно вписывается id датасета:

```json
{"links": {"directionsDataset": "<id из адреса .../datasets/ID>"}}
```

Поле категории — то самое вычисляемое поле с `CONCAT`, которое в визарде стоит
по оси Y. В коде оно названо `Направление`: подставьте его точное имя в
`X_FIELD` (`Prepare.js`) и в `fields` (`Sources.js`).

## Подписи категорий

Две вещи, которых не было в парном чарте:

* **Хвост «— 76» из подписи убирается.** Итог чарт рисует сам в конце полосы,
  а `CONCAT` уже приклеил его к названию — без отсечения одно и то же число
  стоит дважды. Убирается только окончание вида «— <число>»; если его нет,
  подпись остаётся как есть. Выключается через `STRIP_TOTAL_SUFFIX = false`.
* **Колонка подписей подстраивается под содержимое.** Ширина считается по
  самой длинной подписи и ограничена двумя пределами: `maxLabelWidth` (220 px)
  и треть ширины холста. Фиксированное поле либо резало бы «3. Нет работ МЦ
  (платных)», либо на коротких названиях съедало полширины, а на узком
  дашборде не оставило бы места самим полосам. Подпись, не влезшая в колонку,
  усекается многоточием — полный текст виден при наведении.

Порядок категорий берётся из источника: нумерация «1., 1.1, 1.2, 2., 3.» уже
задаёт нужный порядок, а сортировка строк его бы сломала.

## Цифры и итоги

Как в парном чарте: значение стоит внутри своего блока, узкий сегмент
расширяется ровно до ширины подписи, недостающие пиксели снимаются с крупных,
общая длина полосы не меняется. Итог — справа от полосы. Сегменты с нулём не
рисуются: у «1.3 Обр» нулевой «Рефакторинг», в визарде он давал одинокий «0»
у оси.

## Проверка

```
node dev/check.js                # изоляция рендера + четыре размера холста
node dev/preview.js 1000 620     # обновляет preview.html
```

## Что проверено

* Рендер прогнан в Chromium на 1000×620: ошибок нет, все семнадцать значений
  серий стоят внутри своих блоков, итоги 76 / 55 / 12 / 9 / 90 / 69 — в конце
  полос, подписи без дублирующего хвоста.
* Длинная подпись («4. Очень длинное название направления…») усекается
  многоточием, полный текст остаётся в подсказке.
* Узкий холст 480×520: колонка подписей ограничена третью ширины, полосы не
  исчезают. На такой ширине у самых коротких сегментов цифры не помещаются и
  не рисуются — это тот же честный запасной вариант, что и в парном чарте.
* `dev/check.js` проходит на четырёх размерах холста.

Не проверено вживую (нет доступа к инстансу DataLens): поведение
`Editor.generateHtml` на SVG-разметке.
