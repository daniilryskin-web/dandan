# 10. Дерево структуры: сборка Расширенного чарта в DataLens

Полная инструкция по одному чарту — от подключения датасета до размещения
на дашборде. Код каждой вкладки редактора приведён целиком.

Результат: дерево «Ответственный за направление → Проект → Руководитель →
Продукт» с составом команды по уровням ролей на каждом узле.

Ориентировочное время — 20–30 минут.

---

## Часть 0. Что должно быть готово

1. Запущен `prepare_dataset.py`, рядом лежит **`datalens_dataset_tree.csv`**
   (57 строк).
2. На листе «Проверки» в строке «Расхождение ФОТ, руб» стоит **0**.

Если датасет `HR · Иерархия` ещё не создан — сделайте части 1.1–1.3 из
[`08-hierarchy-tab.md`](08-hierarchy-tab.md) и возвращайтесь сюда.

Быстрая проверка, что датасет годится: откройте его и убедитесь, что есть
все двенадцать полей.

```
Блок · Проект · Руководитель · Продукт кратко · риск
R4 · R3 · R2 · R1 · R0 · людей · вакансий · ФОТ_мес
```

---

## Часть 1. Создать чарт

1. **Чарты → Создать чарт**.
2. В выборе типа — **Редактор** (не Мастер).
3. Тип ноды — **Расширенный чарт** (`Advanced Chart`).

Открывается редактор с несколькими вкладками. Дальше по одной.

> В разных версиях DataLens набор вкладок немного отличается: где-то
> «Источники» называются `Urls`, где-то «Параметры» — `Params`. Смысл
> одинаковый, и ниже вкладки названы по смыслу.

---

## Часть 2. Вкладка «Параметры»

Значения по умолчанию для параметров, которые потом придут из селекторов
дашборда. Если фильтровать дерево не планируете — оставьте пустой объект.

```js
module.exports = {
    // Пустая строка = «все». Селектор дашборда подставит сюда своё значение.
    block: '',
    project: ''
};
```

Эти параметры на отрисовку не влияют — их читает только вкладка
«Источники», подставляя в фильтр запроса.

---

## Часть 3. Вкладка «Источники»

Здесь чарт получает данные. В свежих версиях DataLens на этой вкладке
визуальный выбор: кнопка **«Добавить датасет»**, дальше выбираете
`HR · Иерархия` и отмечаете поля галочками. Так проще, и это
предпочтительный путь.

Отметить нужно все двенадцать полей:

```
Измерения:  Блок · Проект · Руководитель · Продукт кратко · риск
Показатели: R4 · R3 · R2 · R1 · R0 · людей · вакансий · ФОТ_мес
```

Порядок полей значения не имеет — код ищет их по названию.

Лимит строк поставьте **1000**: строк всего 57, но при значении по
умолчанию в некоторых версиях приходит только первая сотня, и дерево
молча обрежется.

### Если вкладка принимает код

Точный синтаксис объявления источника различается между версиями, поэтому
не копируйте его вслепую. Возьмите рабочий шаблон одним из двух способов:

- кнопка **«Примеры»** / **«Шаблоны»** в редакторе — там есть готовый чарт
  на датасете, скопируйте из него блок источника;
- документация Редактора вашей инсталляции DataLens.

Идентификатор датасета — из адресной строки при открытом датасете:
`…/datasets/<вот_это>/…`.

**От синтаксиса источника мой код не зависит.** Ему нужно только, чтобы
датасет пришёл в `Editor.getLoadedData()` — как именно вы его туда
положили, неважно. Имя источника тоже неважно: код берёт первый
попавшийся.

---

## Часть 4. Вкладка «JS»

Открыть [`editor/structure-tree.js`](editor/structure-tree.js), скопировать
**целиком** и вставить. Больше на этой вкладке ничего не нужно: файл
самодостаточен, внешних библиотек не подключает, заканчивается
`module.exports` с полным конфигом Highcharts.

Настройки вынесены в начало файла — их и правьте:

```js
var ROW    = 34;                    // высота строки, px
var COL_X  = [0, 214, 434, 648];    // отступ уровня от левого края
var NODE_W = [200, 206, 200, 396];  // ширина узла по уровням
var NODE_H = 30;                    // высота узла
var STRIP  = 5;                     // толщина полосы состава

var VIEW_HEIGHT = 720;              // видимая высота на дашборде
```

**`VIEW_HEIGHT` — самая важная из них.** Полное дерево из 57 строк примерно
2000 px. Виджет дашборда такой высоты не бывает, поэтому чарт остаётся
высотой `VIEW_HEIGHT`, а дерево прокручивается внутри него. Поставьте `0`,
чтобы всегда рисовать целиком — это нужно, если чарт идёт на печать
или в PDF.

---

## Часть 5. Вкладка «Конфигурация»

Настройки самого виджета, не Highcharts. Достаточно минимума:

```js
module.exports = {
    // Кнопка выгрузки и меню чарта не нужны: дерево не выгружается
    // в таблицу осмысленно, для этого есть сводная C7.1.
    hideComments: true
};
```

Если в вашей версии этот ключ не поддерживается — оставьте пустой объект,
на отрисовку это не влияет:

```js
module.exports = {};
```

---

## Часть 6. Вкладка «Селекторы» *(необязательно)*

Нужна, только если хотите фильтр **внутри** чарта, а не на дашборде.
Селекторы дашборда работают и без неё.

Обычно эту вкладку оставляют пустой:

```js
module.exports = {};
```

---

## Часть 7. Сохранить и проверить

1. **Сохранить**, имя — `Структура работ`.
2. Чарт отрисуется прямо в редакторе. Проверьте:

- [ ] четыре колонки узлов слева направо;
- [ ] четыре тёмных узла направлений слева: Ульянов, Зазыкин, Богданова,
      Радужан;
- [ ] на каждом узле полоса и бейдж вида `25-21-8-14-13`;
- [ ] у Ульянова А.Ю. — **81 чел**, бейдж `25-21-8-14-13`
      (25 + 21 + 8 + 14 + 13 = 81);
- [ ] узлов-руководителей ровно **18**;
- [ ] красных рамок продуктов — **8**, жёлтых — **18**;
- [ ] дерево прокручивается внутри чарта по вертикали.

Если сходится — чарт готов.

> Восемь красных и восемнадцать жёлтых — это счёт **узлов**, а не продуктов.
> Продуктов на одном-двух людях 24 из 56; расхождение даёт ФССП, которую
> ведут два руководителя: она попадает в дерево дважды — узлом на 2 человека
> (жёлтый) и узлом на 1 человека (красный).

---

## Часть 8. Положить на дашборд

1. Открыть дашборд → **Добавить → Чарт** → `Структура работ`.
2. Растянуть виджет **на всю ширину** вкладки. Дерево шириной около
   1080 px; в узком виджете появится ещё и горизонтальная прокрутка,
   и пользоваться станет неудобно.
3. Высоту виджета выставить примерно равной `VIEW_HEIGHT` — при 720
   это около 9–10 клеток сетки дашборда. Если виджет ниже чарта,
   прокруток окажется две, вложенные друг в друга.
4. Ничего рядом не ставить: чарт занимает всю строку.

### Селекторы

Селекторы «Блок» и «Проект» с вкладки «Структура» фильтруют дерево как
обычный чарт датасета. Одно но: **связь нужно проставить руками**, если
селектор построен на другом датасете.

Открыть вкладку → **Связи** (иконка цепочки справа вверху) → для селектора
«Блок» проставить связь `по полю Блок` с чартом `Структура работ`. То же
для «Проект».

Проверка: выбрать одно направление. В дереве должна остаться одна ветка,
высота чарта пересчитается сама.

## Часть 9. Если что-то пошло не так

| Симптом | Причина | Что делать |
|---|---|---|
| Чарт пустой, ошибок нет | данные не пришли или названия полей другие | раскомментировать строку DEBUG (см. ниже) |
| «Нет поля «ФОТ_мес». Пришли: …» | поле не добавлено в источник или переименовано | добавить поле на вкладке «Источники» либо поправить название в коде |
| Дерево обрывается на середине | лимит строк в источнике | поставить 1000 |
| Узлы наезжают друг на друга | мало места по вертикали | увеличить `ROW` |
| Название налезает на числа справа | длинные названия продуктов | увеличить `NODE_W[3]` или `TITLE_CH` |
| Дерево не помещается, прокрутки нет | `VIEW_HEIGHT = 0` | вернуть 720 |
| Прокрутки две, вложенные | виджет ниже `VIEW_HEIGHT` | сравнять высоту виджета с `VIEW_HEIGHT` |

**Строка DEBUG** — в файле есть закомментированная строка:

```js
// module.exports = { title: { text: source.fields.join(' | ') } };
```

Раскомментируйте и сохраните: чарт покажет заголовком те названия полей,
которые реально пришли из датасета. Это единственная часть кода, зависящая
от версии DataLens, — если формат ответа отличается, править нужно только
функцию `readSource` в начале файла:

```js
function readSource() {
    var loaded = Editor.getLoadedData();
    var src = loaded[Object.keys(loaded)[0]];
    return {
        fields: (src.fields || []).map(function (f) {
            return f.title || f.legend_item_id || f.guid;
        }),
        rows: (src.result_data[0].rows || []).map(function (r) { return r.values; })
    };
}
```

Она должна вернуть массив названий полей и массив строк-массивов. Остальные
двести строк от формата ответа не зависят вообще.

---

## Что этот чарт не умеет

- **Кликов и тултипов нет.** Вся информация на узле; drill-down до фамилии
  остаётся в сводной таблице C7.1.
- **Тёмная тема не поддерживается** — цвета заданы явно в `THEME`.
- **Переименование поля в датасете ломает чарт.** Он покажет понятную
  ошибку со списком пришедших полей, но чинить придётся в коде.
- **Это дерево структуры работ, а не подчинённости.** Дерево «кто кому
  подчиняется» строится тем же кодом, но требует столбца `ID руководителя`
  в той же нумерации, что и `ФИО (штат)`.

## Что менять при обновлении данных

Ничего. Замените файл в подключении `hr_tree` — чарт перечитает датасет
сам, высота и раскладка пересчитаются. Трогать код нужно, только если
поменялся состав столбцов.
