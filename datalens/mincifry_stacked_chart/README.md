# Advanced-чарт для Yandex DataLens: стек с суммой в итогах, стиль Минцифры

Код для DataLens **Редактора чартов** (Editor / «продвинутый чарт»), тип чарта —
**Графики (`graph`, Highcharts)**. Воспроизводит столбчатый стек из вашего
визарда (Онлайн / Проактив / Рефакторинг по годам) и добавляет то, чего в
визарде нет: **сумму стека над столбцом**, аккуратные подписи внутри сегментов,
тултип с итогом и оформление в палитре дизайн-системы Госуслуг / Минцифры.

## Что куда вставлять

| Файл | Вкладка редактора DataLens |
|---|---|
| `01_params.js` | Параметры |
| `02_sources.js` | Источники (Urls) |
| `03_prepare.js` | JavaScript (Prepare) |
| `04_config.js` | Конфигурация |
| `05_highcharts.js` | Оформление (Highcharts) |
| `06_controls.js` | Элементы управления (UI) |

Порядок запуска: **Создать → Чарт → Редактор → Графики**, затем разложить файлы
по вкладкам и нажать «Сохранить».

## Быстрый старт (без датасета)

В `03_prepare.js` стоит `const DEMO = true` — чарт сразу рисуется на зашитых
цифрах из вашего скриншота (131 / 235 / 98). Убедитесь, что оформление
устраивает, потом переключите на данные:

1. `DEMO = false` в `03_prepare.js`;
2. в `02_sources.js` подставьте `DATASET_ID` из URL датасета
   (`https://datalens.yandex.ru/datasets/<DATASET_ID>`);
3. при необходимости поправьте названия полей — они заданы одной строкой
   в `SERIES_SPEC` / `X_FIELD` в `03_prepare.js` и в `body.fields` в
   `02_sources.js`.

Локально посмотреть оформление можно в браузере: откройте `preview.html`
(тот же Highcharts-конфиг, данные зашиты).

## Сумма в итогах

Итог над столбцом делает `yAxis.stackLabels` в `05_highcharts.js`:

```js
stackLabels: {
    enabled: true,
    crop: false,
    overflow: 'allow',
    formatter: function () { return fmtNumber(this.total); },
}
```

Дополнительно:

* тултип печатает строку **«Всего услуг»** с суммой всех сегментов;
* селектор «Линия итогов» в `06_controls.js` включает пунктирную линию суммы
  поверх стека (аналог вашего «Слоя 2»);
* подписи внутри сегментов скрываются, если сегмент занимает меньше 6 % стека
  (`MIN_LABEL_SHARE`) — иначе мелкие числа наезжают друг на друга, как «5» на
  2027 году.

## Палитра и типографика

Значения собраны в константе `BRAND` — **в двух файлах** (`03_prepare.js` и
`05_highcharts.js`), потому что вкладки редактора изолированы друг от друга и
не могут импортировать общий модуль. Меняете цвет — правьте в обоих.

| Роль | Цвет |
|---|---|
| Основной синий | `#0D4CD3` |
| Акцент / внимание | `#EE3F58` |
| Успех | `#0FA958` |
| Текст | `#0B1F33` |
| Вторичный текст | `#5A7196` |
| Сетка | `#E4E8EE` |
| Фон | `#FFFFFF` |

Гарнитура — **Ubuntu** (шрифт дизайн-системы Госуслуг), со стеком запасных
системных шрифтов: если Ubuntu не установлен на инстансе DataLens, подхватится
следующий. Эти значения — практическая реконструкция фирменного стиля по
публичным материалам, а не выгрузка из брендбука: если у вас есть внутренний
гайд, замените коды в `BRAND` — остальной код трогать не нужно.

## Тонкие места

* **Формат запроса к датасету.** `02_sources.js` использует BI API
  (`/_bi/api/data/v1/datasets/<id>/versions/draft/result`) и ссылается на поля
  по заголовку (`ref: {type: 'title', ...}`). В Yandex Cloud и в
  self-hosted-сборках DataLens версии API расходятся; если источник вернёт
  ошибку — сверьтесь с сетевым запросом, который делает ваш визард (DevTools →
  Network), и поправьте `body.fields`. Разбор ответа в `03_prepare.js`
  (`normalizeRows`) уже понимает и `result_data`, и простой массив объектов,
  так что менять придётся только вкладку источников.
* **Функции-форматтеры** живут во вкладке «Оформление»: при передаче через
  `ChartEditor.updateHighchartsConfig()` из JS-вкладки они теряются при
  сериализации.
* **Режим `percent`** отключает линию итогов — сумма долей всегда 100 %.
