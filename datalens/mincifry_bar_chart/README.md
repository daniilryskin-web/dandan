# Advanced-чарт DataLens: горизонтальный стек с суммой в итогах

Второй чарт из пары: полосы по годам, разложенные по уровням власти, с суммой
в конце каждой полосы. Тип визуализации — **Advanced-чарт**, оформление то же,
что у вертикального стека в `../mincifry_stacked_chart`.

## Раскладка по вкладкам

| Файл | Вкладка |
|---|---|
| `Meta.json` | Meta |
| `Params.js` | Params |
| `Sources.js` | Sources |
| `Prepare.js` | Prepare |
| `Controls.js` | Controls |

Это отдельная сущность в DataLens, поэтому набор вкладок свой. Общего модуля у
вкладок нет — палитра продублирована в `Prepare.js` обоих чартов, менять цвета
придётся в двух местах.

## Подключение датасета

Во вкладку **Meta** обязательно вписывается id датасета:

```json
{"links": {"levelsDataset": "<id из адреса .../datasets/ID>"}}
```

Без этого чарт падает с `Source with id "" was not found in the meta links`.
`Sources.js` проверяет id сам и пишет, что именно заполнить.

Названия полей — в `SERIES_SPEC` / `X_FIELD` (`Prepare.js`) и в `fields`
(`Sources.js`). Ключ источника `levels` должен совпадать с `SOURCE_KEY`.

Демо-режима в коде нет: `Prepare.js` всегда читает данные источника. Данные
для локального предпросмотра лежат в `dev/fixture.js`.

## Сумма в итогах

Итог рисуется в конце полосы, справа от последнего сегмента. В режиме долей
полосы нормируются к 100 %, а подпись справа остаётся абсолютной.

## Цифры внутри блоков

Здесь ограничение другое, чем у вертикального стека: цифру ограничивает не
высота, а **ширина** сегмента, и требуемая ширина зависит от самой подписи —
«107» шире, чем «1». Поэтому для каждого сегмента считается своя минимальная
ширина (`ширина текста + 12 px`), узкие расширяются ровно до неё, а недостающие
пиксели снимаются с крупных сегментов пропорционально их запасу. Общая длина
полосы не меняется — конец полосы и подпись итога остаются на своём месте
по шкале.

Цена та же, что и в вертикальном чарте: пропорции внутри полосы слегка
искажаются, когда сегмент узкий. `fitLabels: false` выключает подгонку.

Сегменты с нулём не рисуются и подписи не получают — в вашем визарде за 2027 год
из-за нулевого «Федерального/Регионального» на оси висел одинокий «0».

## Настройки в модели

| Ключ | Что делает |
|---|---|
| `barThicknessRatio` | толщина полосы как доля слота (0.5) |
| `maxBarThickness` | предел толщины в пикселях (56) |
| `fitLabels` | подгонять ли узкие сегменты под подпись |
| `titleX` | отступ заголовка от левого края холста |

## Проверка

```
node dev/check.js               # изоляция рендера + четыре размера холста
node dev/preview.js 960 460     # обновляет preview.html
```

`dev/check.js` пересобирает функцию рендера в чистом контексте, где доступен
только `Editor`. Это ловит обращения к переменным вне `wrapFn`: локальная
заглушка их не замечает, потому что функция остаётся замыканием, а в DataLens
такой код падает с `ReferenceError`.

## Что проверено

* Рендер прогнан в Chromium: 960×460 в абсолютных значениях и в долях, узкий
  контейнер 480×420. Ошибок нет, все двенадцать значений серий стоят внутри
  своих блоков, итоги 133 / 235 / 98 — в конце полос.
* `dev/check.js` проходит на четырёх размерах холста.
* Палитра из четырёх ступеней прогнана валидатором категориальных наборов:
  светлота, насыщенность, различимость при дальтонизме (худшая соседняя пара
  ΔE 11.7 при протанопии), контраст к фону ≥ 3:1 — всё пройдено.

Не проверено вживую (нет доступа к инстансу DataLens): поведение
`Editor.generateHtml` на SVG-разметке.
