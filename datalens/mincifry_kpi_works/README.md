# Advanced-чарт DataLens: индикаторы стадий работ

Четыре индикатора одним кодом: «Всего услуг в работе» (70), «Работы не
начаты» (29), «Реализовано услуг» (39) и «Всего услуг» (235). Числа берутся
из строки `Тип = ВСЕГО` того же датасета, что и стек стадий
(`../mincifry_bar_chart_works`).

## Четыре чарта — один код

В DataLens это четыре отдельные сущности, но код у них общий: создайте четыре
Advanced-чарта с одинаковыми вкладками и в каждом поменяйте **одну строку** в
`Prepare.js`:

```js
const ACTIVE = 'inWork';   // 'inWork' | 'notStarted' | 'done' | 'total'
```

| `ACTIVE` | Заголовок | Что показывает |
|---|---|---|
| `inWork` | Всего услуг в работе | «2. В работе» |
| `notStarted` | Работы не начаты | «1. Работы не начаты» |
| `done` | Реализовано услуг | «3. Реализовано» |
| `total` | Всего услуг | сумма всех четырёх стадий |

Четыре копии файла с двумя различающимися строками разошлись бы при первой же
правке — поэтому переключатель, а не четыре папки. Заголовки и имена полей
лежат рядом, в `INDICATORS`.

## Подключение датасета

```json
{"links": {"worksDataset": "<id из адреса .../datasets/ID>"}}
```

`Sources.js` запрашивает все четыре стадии, а не только показываемую: из них
считается знаменатель, и один и тот же источник годится для всех четырёх
чартов. У полей есть запасные имена без суффикса «(индикатор)».

## Полоса и знаменатель

Под числом полоса заполнения и подпись «из 235»: само по себе «70» не
говорит ни о чём, а доля от целого читается сразу. Знаменатель — сумма
четырёх стадий в той же строке (`DENOMINATOR_FIELDS`); пустой список убирает
полосу.

У варианта `total` полосы нет намеренно: она была бы всегда полной.

Итог считается сложением стадий, потому что в запросе нет отдельного поля с
ним. Если в датасете такое поле есть, замените вариант `total` на обычный —
с `field` и `aliases`, как у остальных.

## Если индикатор показывает прочерк

Причина пишется под прочерком: источник не вернул строк; в ответе нет поля
«Тип» (с перечислением пришедших); строки `ВСЕГО` нет (с перечислением
значений, которые есть); строка найдена, но поле пустое; сумма стадий равна
нулю. Сравнение значений мягкое — неразрывный пробел, двойные пробелы и
регистр совпадению не мешают.

## Проверка

```
node dev/check.js               # изоляция рендера + четыре размера холста
node dev/preview.js 420 210     # обновляет preview.html
```

## Что проверено

* Все четыре варианта прогнаны на данных из стека: 70, 29, 39 и 235 — с
  подписью «из 235» у первых трёх и без полосы у итога.
* Рендер в Chromium: ошибок нет, число и полоса не выходят за холст 420×210.
* `dev/check.js` проходит на четырёх размерах холста.

Не проверено вживую (нет доступа к инстансу DataLens): поведение
`Editor.generateHtml` на SVG-разметке и точные имена полей.
