Бот приёмки видеозаписей «Показы работ по контрактам ИЭП»
Комплект для установки на рабочий компьютер. Редакция от 01.10.2026.

С чего начать — «Инструкция по установке.docx».

Состав
  priemka-bot\                  программа, копируется в C:\priemka-bot
    setup.cmd                   установка: правой кнопкой — «Запуск от имени администратора»
    start-bot.cmd               запуск бота, его вызывает Планировщик заданий
    stop-bot.cmd                остановка бота
    bot.js, yandex-disk.js,
    max-upload.js, journal.js,
    config.js, ui.js, meta.js,
    xlsx.js                     исходный код бота
    tools\check.js              проверки (временные ссылки, ширина дерева папок)
    test\                       автотесты (для проверки, боту не нужны)
    package.json                описание программы, внешних библиотек нет
    access.json                 кому разрешено пользоваться ботом
  SHA256SUMS.txt                контрольные суммы файлов программы

Токены доступа к MAX и Яндекс.Диску в комплект не входят и передаются отдельно.
Node.js в комплект не входит: ставится с nodejs.org, версия LTS 22 или новее (рекомендуется 24).

Разработчик — Эмиль Халилов.

Обновление с прежних редакций
  Остановить бота (stop-bot.cmd), заменить ВСЕ файлы из папки priemka-bot,
  включая новые config.js, ui.js, meta.js, xlsx.js, — без них бот не запустится. .env, access.json,
  state.json и marker.json не трогать. Запустить: schtasks /run /tn PriemkaBot
  Старый .env подходит без правок.

Дополнительные настройки в .env (необязательные, у каждой есть значение по умолчанию)
  ADMINS=90235418                 основные администраторы через запятую
  YANDEX_TOKEN_ISSUED=2026-09-07  дата выдачи токена Диска — бот напомнит о продлении
  YANDEX_TOKEN_DAYS=365           срок жизни токена в днях
  LOW_SPACE_GB=10                 порог свободного места для оповещения
  SUMMARY_HOUR=9                  с какого часа слать утреннюю сводку администратору
  DISK_ROOT=Видеопоказы           корневая папка на Диске (для тестового контура —
                                  другая, например Видеопоказы-тест)
  Если в .env есть русские буквы (DISK_ROOT), сохраняйте его в Блокноте в кодировке
  «UTF-8» (не «UTF-8 с BOM» и не ANSI) — иначе название папки исказится.

Оповещения администратору приходят в его чат с ботом. Чат бот запоминает,
когда администратор хоть раз напишет ему, — после обновления отправьте боту /start.

Тестовый контур: отдельная копия папки бота с .env, где указан токен ВТОРОГО
(тестового) бота MAX и DISK_ROOT=Видеопоказы-тест. Два бота с одним токеном
одновременно запускать нельзя.

Автотесты: в папке бота выполнить  node --test   (в сеть тесты не ходят).

Что нового в редакции 01.10.2026 (вторая часть)
  - заявка на доступ кнопкой; смена роли без удаления человека;
  - обзор записей по папкам (руководители и администраторы) и карточка записи;
  - версии записи из архива и восстановление; удаление — только в архив;
  - комментарии к записям (хранятся на Диске в папке _Служебное);
  - «Ещё запись сюда», «В прошлую папку», сверка номера с именем файла;
  - подтверждение замены «было → станет», ход загрузки, шаги и страницы кнопок;
  - утренняя сводка, последние действия, журнал и список доступа в Excel;
  - сверка с реестром номеров (.xlsx или .csv), список команд в MAX.

Реестр записей со ссылками (для дашборда Yandex DataLens)
  «Отчёты» → «Реестр записей со ссылками». Бот открывает каждой записи публичную ссылку
  Яндекс.Диска и выгружает таблицу. Копия: <корень>/_Отчёты/Реестр записей.xlsx, обновляется
  каждое утро. Старые версии и удалённые записи теряют ссылку автоматически.
  Закрыть все ссылки разом: «Отчёты» → «Закрыть все публичные ссылки».
